# ResumeDemo
基于C语言实现的简历管理系统，支持求职者、招聘者、管理员多角色操作。

## 功能模块
- 用户登录/注册
- 简历录入、修改、删除、查看
- 招聘岗位发布、搜索、投递
- 数据自动保存与读取

## 项目结构
├── 0. 全局结构体.h // 全局结构体、变量定义
├── 1. 用户登录注册.h // 用户登录注册模块
├── 2. 求职者菜单.h // 求职者功能菜单
├── 3. 招聘者菜单.h // 招聘者功能菜单
├── 4. 录入简历.h // 简历录入模块
├── 5. 查看我的简历.h // 简历查看模块
├── 6. 修改我的简历.h // 简历修改模块
├── 7. 删除我的简历.h // 简历删除模块
├── 8. 发布招聘岗位.h // 岗位发布模块
├── 9. 查看所有岗位.h // 岗位查看模块
├── 10. 按要求搜索岗位.h // 岗位搜索模块
├── 11. 投递简历.h // 简历投递模块
├── 12. 招聘者查收到的简历.h// 招聘者简历查看
├── 13. 按求职意向搜简历.h // 简历筛选模块
├── 14. 自动保存全部数据.h // 数据自动保存
├── 15. 自动读取全部数据.h // 数据自动读取
└── main.c // 程序主入口
## 运行环境
- Windows 10/11
- Visual Studio 2022
- C语言标准 C11
